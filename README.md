# AntAdventure (React Version)

남극탐험 컨셉의 웹게임입니다. React와 Vite를 사용하여 개발되었습니다.

## 실행 방법

1. 의존성 설치
   ```bash
   npm install
   ```

2. 개발 서버 실행
   ```bash
   npm run dev
   ```

3. 빌드
   ```bash
   npm run build
   ```

## 프로젝트 구조

*   `src/App.jsx`: 메인 게임 로직 및 렌더링
*   `src/utils/audio.js`: Web Audio API 관련 로직
*   `src/index.css`: 스타일 시트
*   `index.html`: 진입점
